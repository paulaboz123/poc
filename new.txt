Run the slide descriptions (if you haven’t yet). This lets Claude understand the diagrams on the original slides, not just their text:

uv run pipeline.py --mode easy --vision

New video. Use a new plan: --rerender would only redraw the old plan, which still has the screenshots in it.

uv run make_video.py --recording "<part of the title>" --minutes 2 --plan-only

In script.md you’ll see a type next to each scene (comparison, table, concept, steps...) and the text that will appear on the new slide. If it’s OK:

uv run make_video.py --rerender "data\output\<new folder>" --check

If you ever want to show an original slide (e.g. a complex diagram), add ORIGINAL_SLIDES=yes to .env. By default it’s off.
